CyberArena: Autonomous AI Agent Cybersecurity Platform

CyberArena is an autonomous AI agent experimentation platform designed for isolated cybersecurity research and security evaluation. It provides an interactive web dashboard for orchestrating, observing, and evaluating autonomous AI agents operating inside dedicated, isolated Linux virtual machines powered entirely by local Large Language Models (via Ollama).

Architecture Overview

  • Frontend Dashboard (React + TypeScript + Vite): Features live interactive terminal controls, local LLM diagnostics, model selectors, and real-time multi-agent execution timelines.
  • CyberArena Backend (FastAPI): Manages the autonomous ReAct loop (Thought → Tool Call → Observation), multi-agent concurrent scheduling, and security policy enforcement.
  • Hypervisor & Guest Virtualization: Oracle VirtualBox host-only network (192.168.32.x) with target Ubuntu VMs executing commands via isolated Paramiko SSH sessions.
  • Local Inference Engine (Ollama): 100% offline local inference with zero cloud dependency and zero sensitive data leakage.

Key Capabilities & Features

  • Strict Hypervisor & Network Isolation: Target virtual machines run on a dedicated host-only subnet with strict SSH command sandboxing, protecting the host operating system from rogue commands.
  • Autonomous Multi-Agent ReAct Execution: Agents independently plan steps, execute guest commands, observe actual outputs, adapt strategies based on errors, and synthesize evidence-backed conclusions.
  • Privileged Guest Tools with Auto-Elevation: Suite of tools for administrative operations (execute_command, install_package, restart_service, modify_system_config, create_user, read_file, write_file) with automated sudo escalation.
  • Destructive Operation Guardrails: Strict security policies intercept and neutralize hazardous operations such as recursive root deletion (rm -rf /), raw disk overwrite, filesystem reformatting, and fork bombs.
  • Anti-Repetition Intelligence: Runtime loop and guided system prompts prevent LLMs from looping or re-executing failed commands.
  • Real-Time Observability: Live terminal output streaming, agent thought logs, and interactive milestone graphs via WebSockets and Server-Sent Events.
  • Clean Baseline Snapshot Rollback: Instant snapshot creation and restore capability to ensure clean testing baselines across evaluation runs.
