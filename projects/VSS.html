Video Synthesis System

A AI Pipe-Line that takes in a topic name and then generates a video explaining the topic covering various key points.

Technical Details

  • Modular pipeline separating script generation, rendering, and audio merging
  • Local high-performance LLM (Ollama suggested) ensuring offline text generation
  • Manim for deterministic, precise animated explainer visuals
  • FFmpeg for robust media processing and final export handling

Key Features

  • Automated topic-to-video workflow from text generation to final multimedia output
  • Voiceover synthesis integrated with scene timing adjustments (Not-Precise)
  • Reusable video blueprint JSON making programmatic edits easy
  • Defense against high paid API dependency
